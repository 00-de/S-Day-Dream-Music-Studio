SDayDream Music Studio — Phase 3 設定手順（APIキーの入れ方）

■ どれか1つあれば動きます
  GROQ_API_KEY    … おすすめ。無料枠があり、返答が速い
  GEMINI_API_KEY  … Google AI Studio で取得
  OPENAI_API_KEY  … 有料

■ キーの取り方
  Groq   : https://console.groq.com  → API Keys → Create API Key
  Gemini : https://aistudio.google.com → Get API key
  OpenAI : https://platform.openai.com → API keys

■ Vercel への入れ方（すべてブラウザ操作）
  1. Vercel でこのプロジェクトを開く
  2. Settings → Environment Variables
  3. Key に  GROQ_API_KEY  、Value に取得したキーを貼る
  4. Environments は Production / Preview / Development すべてにチェック
  5. Save
  6. Deployments → 最新のものの「…」→ Redeploy
     ※ 環境変数は再デプロイしないと反映されません

■ 確認
  アプリの「設定」画面 →「接続を確認」を押す
  「接続あり： groq」と出れば成功です

■ モデルを変えたいとき（任意）
  GROQ_MODEL / GEMINI_MODEL / OPENAI_MODEL を追加すると差し替えられます
  既定値: llama-3.3-70b-versatile / gemini-2.0-flash / gpt-4o-mini

■ 注意
  ・APIキーはサーバー側だけで使われ、ブラウザには渡していません
  ・index.html をPCで直接開いた状態ではAI機能は動きません（Vercel上でのみ動作）
  ・キーが未設定でも、これまでの下書き生成と作曲機能はそのまま使えます
